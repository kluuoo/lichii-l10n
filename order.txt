300 | ConfigurationShared | Precache shaders before game start:
301 | ConfigurationShared | Builds shaders on the loading screen, on every CPU thread, so they don't stutter the first time the game uses them: the compute shaders found in the game files, and the shaders saved by earlier play sessions that the normal shader loading leaves for later. The first launch reads the game files and takes a few minutes; later launches only build what is new, until the GPU driver changes. The loading screen has a Skip button.\nAsk asks at launch while the game has never been precached.
302 | ConfigurationShared | Switch 2 draws with unbuilt pipelines:
303 | ConfigurationShared | Only applies when asynchronous shader building is on. Decides what a Switch 2 draw does when its graphics pipeline is still building.\nWait stalls the GPU until the pipeline is ready (no missing effects, but long stalls on new content). Skip drops the draw, which can leave an effect missing for a few frames. Bounded waits up to the time below per frame, then skips. The EDEN_NX2_ASYNC_DISCARD=1 environment variable still forces Skip.
304 | ConfigurationShared | Pipeline wait per frame (ms):
305 | ConfigurationShared | Used by the Bounded mode: the most time per frame that Switch 2 draws may wait in total for pipelines that are still building. Once spent, the remaining unbuilt draws of that frame are skipped.
