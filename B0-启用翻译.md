## 1. 打开翻译开关（必需）

`CMakeLists.txt:75`：

```diff
-option(ENABLE_QT_TRANSLATION "Enable translations for the Qt frontend" OFF)
+option(ENABLE_QT_TRANSLATION "Enable translations for the Qt frontend" ON)
```

或者在每次 configure 时显式传：

```bash
cmake -B build -DENABLE_QT_TRANSLATION=ON ...
```

打开后 `src/yuzu/CMakeLists.txt:293-373` 会：

- 用 `qt_add_translation()` 把 `dist/languages/*.ts` 编成 `.qm`；
- 生成 `languages.qrc` 并把 `.qm` 编进 `yuzu` 目标（运行时从 `:/languages/` 读取）。

> 前提：构建机装有 Qt LinguistTools（提供 `lrelease`）。Linux 一般是
> `qt6-tools-dev` / `qttools6-dev-tools`，Windows 的 Qt 安装包自带 `lrelease.exe`。

## 3. 加载 Qt 自带翻译（让“是 / 否 / 取消”、右键菜单变中文）

目前 `src/yuzu/main.cpp` 只装了应用自己的 `QTranslator`（在 `MainWindow::LoadTranslation`
里，见 `main_window.cpp:5681`），Qt 标准对话框用的是 `qtbase_*.qm`，从未加载。

在 `src/yuzu/main.cpp` 顶部加：

```cpp
#include <QCoreApplication>
#include <QLibraryInfo>
#include <QTranslator>
```

在 `QApplication` 构造之后、创建主窗口之前加一个函数并调用（文件里已有 `main()`，
把函数放在 `main()` 上方即可）：

```cpp
static QTranslator* g_qt_translator = nullptr;

static void LoadQtTranslation() {
    static const QString locale =
        (UISettings::values.language.GetValue().empty()
             ? QLocale::system().name()
             : QString::fromStdString(UISettings::values.language.GetValue()));

    const QStringList dirs{
        QLibraryInfo::path(QLibraryInfo::TranslationsPath),
        QCoreApplication::applicationDirPath() + QStringLiteral("/translations"),
    };

    delete g_qt_translator;
    g_qt_translator = new QTranslator(QCoreApplication::instance());
    for (const QString& dir : dirs) {
        if (g_qt_translator->load(QStringLiteral("qtbase_") + locale, dir)) {
            QCoreApplication::installTranslator(g_qt_translator);
            return;
        }
    }
    delete g_qt_translator;
    g_qt_translator = nullptr;
}
```

调用点：`main()` 里 `QApplication app(argc, argv);` 之后立即 `LoadQtTranslation();`。

> 注意：`UISettings::values.language` 在 `MainWindow` 构造时才可用；如果 `main()`
> 里 `QApplication` 之后读它还太早，可以先按 `QLocale::system()` 加载，等
> `MainWindow::OnLanguageChanged()` 时再重新加载一次（把 `LoadQtTranslation()`
> 也调用一遍）。两条路径都在 `configure_ui.cpp` 里可挂。

## 4. 语言下拉框显示原生名称（“简体中文”而不是“Chinese (China)”）

`src/yuzu/configuration/configure_ui.cpp:226-244` 目前用 `QLocale::languageToString()`
拼名字，而该函数依赖 Qt 翻译文件；翻译没装时永远显示英文名。

在 `InitializeLanguageComboBox()` 中改为“原生名优先、回退 QLocale”：

```cpp
void ConfigureUi::InitializeLanguageComboBox() {
    ui->language_combobox->addItem(tr("<System>"), QString{});
    ui->language_combobox->addItem(tr("English"), QStringLiteral("en"));

    // 语言自带名称；缺省时回退到 QLocale 的英文名
    static const std::map<QString, QString> native_names{
        {QStringLiteral("ar"), QStringLiteral("العربية")},
        {QStringLiteral("ca"), QStringLiteral("Català")},
        {QStringLiteral("cs"), QStringLiteral("Čeština")},
        {QStringLiteral("da"), QStringLiteral("Dansk")},
        {QStringLiteral("de"), QStringLiteral("Deutsch")},
        {QStringLiteral("el"), QStringLiteral("Ελληνικά")},
        {QStringLiteral("es"), QStringLiteral("Español")},
        {QStringLiteral("fi"), QStringLiteral("Suomi")},
        {QStringLiteral("fr"), QStringLiteral("Français")},
        {QStringLiteral("hu"), QStringLiteral("Magyar")},
        {QStringLiteral("id"), QStringLiteral("Bahasa Indonesia")},
        {QStringLiteral("it"), QStringLiteral("Italiano")},
        {QStringLiteral("ja_JP"), QStringLiteral("日本語")},
        {QStringLiteral("ko_KR"), QStringLiteral("한국어")},
        {QStringLiteral("nb"), QStringLiteral("Norsk bokmål")},
        {QStringLiteral("nl"), QStringLiteral("Nederlands")},
        {QStringLiteral("pl"), QStringLiteral("Polski")},
        {QStringLiteral("pt_BR"), QStringLiteral("Português (Brasil)")},
        {QStringLiteral("pt_PT"), QStringLiteral("Português (Portugal)")},
        {QStringLiteral("ru_RU"), QStringLiteral("Русский")},
        {QStringLiteral("sv"), QStringLiteral("Svenska")},
        {QStringLiteral("tr_TR"), QStringLiteral("Türkçe")},
        {QStringLiteral("uk"), QStringLiteral("Українська")},

        ui->language_combobox->addItem(label, locale);
    }

}
```
